## Bookmarks Section

* Adds bookmarks section for the library so you can now manage your bookmarks directly from the library :)
* In case you are wondering, the bookmarks section behaves almost the same as the native bookmarks panel.

  <img width="1502" height="901" alt="image" src="https://github.com/user-attachments/assets/40de083e-576a-47f3-8270-eb577c8ca3b1" />

* Also a nice custom animated icon for bookmarks! In my opinion it looks really nice.

  https://github.com/user-attachments/assets/14fb909a-3c80-434b-8125-307efadd8b30

* Supports search based on bookmark keyword too.
* And also supports filtering based on Tags, and Workspaces.

  <img width="380" height="370" alt="image" src="https://github.com/user-attachments/assets/5a4c11c7-42ec-4687-a88b-e881fb9ab513" />

## History Section

* The history section now has Recently closed tabs and Clear recent history... buttons!

  <img width="382" height="163" alt="image" src="https://github.com/user-attachments/assets/2a832a2c-e145-4346-8c76-8ce2f5a984bb" />

* Recently closed tabs button shows the items nicely.

  <img width="1502" height="901" alt="image" src="https://github.com/user-attachments/assets/8388f324-5d75-4cfa-aac4-695889f6648e" />

* This tweak to the history section can be turned off in the mod preferences.

## Boosts Section

* The boosts section now shows the boosts grouped by website by a header of the URL on top.

  <img width="375" height="263" alt="image" src="https://github.com/user-attachments/assets/34a49c3f-4726-4a2b-8d7f-3ec8361f6ba6" />

* This tweak to the boosts section can be turned off in the mod preferences.

## Installation

- Install **Sine** if you don’t already have it  
   https://github.com/CosmoCreeper/Sine
- Open **Settings → Sine Mods** (or **Cosine**)
- Click the settings icon (opens sine's settings)
   
  <img width="618" height="82" alt="image" src="https://github.com/user-attachments/assets/b1f9994a-e193-405d-b6df-36d4c1331042" />

- Check "Enable installing JS from unofficial sources. (unsafe, use at your own risk)"

  <img width="750" height="493" alt="image" src="https://github.com/user-attachments/assets/3c26c0f1-d6b9-4dbb-b1ec-770823a07d5f" />
